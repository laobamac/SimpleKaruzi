## ✨ **Features**

1.  **Comprehensive Hardware & macOS Support**  
    Fully supports modern hardware. Use the `Compatibility Checker` to check supported/unsupported devices and supported macOS versions.

    | **Component** | **Support Status**                                                                                                                               |
    |---------------|-------------------------------------------------------------------------------------------------------------------------------------------|
    | **CPU**       | Intel: Nehalem & Westmere (Gen 1) → Arrow Lake (Gen 15 / Core Ultra Series 2) <br> AMD: Ryzen and Threadripper series using [AMD Vanilla](https://github.com/AMD-OSX/AMD_Vanilla) |
    | **GPU**       | Intel iGPU: Iron Lake (Gen 1) → Ice Lake (Gen 10) <br> AMD APU: Entire Vega Raven ASIC family (Ryzen 1xxx → 5xxx, 7x30 series) <br> AMD dGPU: Navi 23, Navi 22, Navi 21 generations and older series <br> NVIDIA: Kepler, Pascal, Maxwell, Fermi, Tesla generations |
    | **macOS**     | macOS High Sierra → macOS Tahoe |

2.  **ACPI Patches & Kexts**  
    Automatically detects and adds ACPI patches and kexts based on hardware configuration.

    - Integrates [SSDTTime](https://github.com/corpnewt/SSDTTime) to apply common patches (e.g., FakeEC, FixHPET, PLUG, RTCAWAC).
    - Includes custom patches:
        - Prevents kernel panics by redirecting the first CPU entry to the active CPU, disabling UNC0 devices, and creating new RTC devices for HEDT systems.
        - Disables unsupported or unused PCI devices, such as GPUs (using Optimus and Bumblebee methods or adding disable-gpu property), Wi-Fi cards, and NVMe storage controllers.
        - Fixes sleep state values in _PRW methods (GPRW, UPRW, HP special) to prevent instant wake.
        - Adds devices including ALS0, BUS0, MCHC, PMCR, PNLF, RMNE, IMEI, USBX, XOSI, and a Surface patch.
        - Enables ALSD and GPI0 devices.

3.  **Automatic Updates**  
    - When opening `SimpleKaruzi` for the first time, it will automatically prompt whether to pull the SKSP (SimpleKaruzi Support PKG) to facilitate quick EFI output later.
    - Before each EFI build, automatically checks for updates for OpenCorePkg and kexts within SKSP from [Dortania Builds](https://dortania.github.io/builds/) and GitHub.

4.  **EFI Configuration**  
    Applies additional custom configurations based on widely used sources and personal experience.

    - Spoofs GPU IDs for certain AMD GPUs not recognized in macOS.
    - Uses CpuTopologyRebuild kext for Intel CPUs with P-cores and E-cores to improve performance.
    - Disables System Integrity Protection (SIP).
    - Spoofs CPU IDs for Intel Pentium, Celeron, Core, and Xeon processors.
    - Adds custom CPU names for AMD CPUs and Intel Pentium, Celeron, Xeon, and Core series from Rocket Lake (Gen 11) onwards.
    - Adds patches allowing booting macOS with unsupported SMBIOS.
    - Adds NVRAM entries to bypass internal Bluetooth controller checks.
    - Correctly configures ResizeAppleGpuBars based on specific Resizable BAR information.
    - Allows flexible configuration of iGPU between headless mode and driving displays when a supported dGPU is present.
    - Forces Intel GPUs into VESA mode and enables HDMI and DVI connectors to simplify the installation process.
    - Provides necessary configurations for using OCLP(-Mod).
    - Adds built-in device properties for network devices (fixing "Unable to communicate with the server" errors with iServices) and storage controllers (fixing internal drives appearing as external).
    - Prioritizes SMBIOS optimized for power management and performance.
    - Re-enables CPU power management for older Intel CPUs in macOS Ventura 13 and newer.
    - Applies WiFi profiles for itlwm kext to enable automatic WiFi connection at boot.

    And much more...

5.  **Easy Customization**  
    Besides applying default settings, users can easily make further customizations as needed.

    - Customize ACPI patches, kexts, and SMBIOS adjustments (**Not Recommended**).
    - Force load kexts on unsupported macOS versions.

## 🚀 **How to Use**

1.  **Download SimpleKaruzi**:
    - Click **Releases** → **Download Latest Release**, or go to the Releases page via this [link](https://github.com/laobamac/SimpleKaruzi/releases).
    - For `macOS`, please copy `SimpleKaruzi.app` inside the downloaded DMG to the `/Applications` folder as prompted.
    - For `Windows`, simply unzip and run `SimpleKaruzi.exe`.

2.  **Run SimpleKaruzi**:
    - Main Page (Supports Light/Dark themes, follows system by default)
    ![SimpleKaruzi Light](https://img.wjwj.top/2026/01/11/6998416be8c192a18e73ff190e6ff67c.png)
    ![SimpleKaruzi Night](https://img.wjwj.top/2026/01/11/97a4a2f95f2288e2ed8d52858c40063c.png)

    - When opening `SimpleKaruzi` for the first time, it will automatically prompt whether to pull the SKSP (SimpleKaruzi Support PKG) to facilitate quick EFI output later.
    - You can also regularly check and update SKSP within the settings page.
    ![SKSP](https://img.wjwj.top/2026/01/11/97c744479adfb59557c9a05b18ff4506.png)

4.  **Select Hardware Report**:
    - On Windows, there will be an `Export Hardware Report` button. It is recommended to use this option to get the best results matching your hardware configuration and BIOS during build.
    - Alternatively, use [**Hardware Sniffer**](https://github.com/lzhoang2801/Hardware-Sniffer) to create `Report.json` and ACPI dumps for manual configuration.

    ![Select Hardware Report](https://img.wjwj.top/2026/01/11/76882544d943062e8e5dd9928023efbf.png)
    ![Compatibility Checker](https://img.wjwj.top/2026/01/11/aaa2b64a32aac6e667810ef67c1a19b4.png)

    - Of course, you can also choose to view detailed information.
    ![Detailed Information](https://img.wjwj.top/2026/01/11/922644e4090cc174f9c60b4588e9d8fd.png)

6.  **Select macOS Version & Customize OpenCore EFI**:
    - By default, the latest compatible macOS version for your hardware will be selected.
    - SimpleKaruzi will automatically apply necessary ACPI patches and kexts.
    - You can manually review and customize these settings if needed.

    ![SimpleKaruzi Menu](https://img.wjwj.top/2026/01/11/b6b7231b169171690f041e588779a2e0.png)

7.  **Build OpenCore EFI**:
    - After customizing all options, select **Build OpenCore EFI** to generate your EFI.
    - The tool will automatically download necessary bootloaders and kexts, which may take a few minutes.

9.  **USB Mapping**:
    - After building your EFI, follow the steps for USB port mapping.

    ![Result](https://img.wjwj.top/2026/01/11/b258f077217def5e893823b77ece8706.png)

10. **Create USB Installer & Install macOS**:
    - On Windows, use [**UnPlugged**](https://github.com/corpnewt/UnPlugged) to create a USB macOS installer, or on macOS follow [this guide](https://dortania.github.io/OpenCore-Install-Guide/installer-guide/mac-install.html).
    - For troubleshooting, refer to the [OpenCore Troubleshooting Guide](https://dortania.github.io/OpenCore-Install-Guide/troubleshooting/troubleshooting.html).

> [!NOTE]
> 1. After successful installation, if you need to use OCLP(-Mod), simply apply root patches to activate missing features (e.g., modern Broadcom Wi-Fi cards and graphics acceleration).
>
> 2. For AMD GPUs, after applying root patches with OCLP(-Mod), you need to remove boot args `-radvesa`/`-amd_no_dgpu_accel` for graphics acceleration to work.
